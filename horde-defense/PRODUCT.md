# Lastlight: Horde Defense

## Platform

Native desktop PC game, mouse and keyboard. The skill's web/mobile taxonomy does not describe this Bevy application.

## Stack

User requested a new Bevy experiment. Rust 1.99.1, Bevy 0.20, independent Cargo workspace; pure simulation and native egui presentation.

## Users and purpose

Single-player survivors defend a fixed position across deployment-frozen lanes, earn retained rewards, improve their character, train a replacement survivor, and build fortifications. Success means the complete campaign loop described in docs/GDD.md is playable.
