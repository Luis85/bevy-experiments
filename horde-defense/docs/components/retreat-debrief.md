# Settled main-round outcome

Read the last settled round before choosing the next action.

The outcome strip names victory/defeat/retreat, country/stage and already-banked coins/items. It does not pay again or independently deploy. Every outcome shares the Journey upgrades home; the retained ID identifies this informational portion of the former debrief surface.

Parent IDs express containment, not exclusive entry routes. Implemented records source presence, not native interaction or performance validation.
