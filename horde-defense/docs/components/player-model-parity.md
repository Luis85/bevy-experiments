# Original source parity

Compare the unsplit original source with actual emitted part assembly on black and white at source resolution. Inspect both survivors and write the real audit manifest. Require zero differences without tolerance or screenshot rewriting.

Accepted original-bind evidence does not establish posed animation, garments, integration or performance.

This is a source-backed developer task. Implemented records source presence, not a final native, interactive or performance verdict.
