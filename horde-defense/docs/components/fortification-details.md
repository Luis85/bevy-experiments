# Selected fortification node

Inspect the selected blueprint or structure-rank node in the common requirement panel.

Ownership, prior rank, prerequisites, milestones, payment and unavailable reasons come from the same core node kernel. Selection never purchases. Old separate blueprint/rank controls are not additional transaction paths.

Parent IDs express containment, not exclusive entry routes. Implemented records source presence, not native interaction or performance validation.
