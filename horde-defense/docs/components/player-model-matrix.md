# Equipped and action model matrix

Inspect original/selected equipment, missing slots, firearm classes, outfits, directions, action phases and reduced effects through the production pose/texture facade. Actual geometry/contact metadata accompanies the PNG.

Both heroes require native review; supported cases and mathematical contacts alone do not approve silhouettes, seams, grips or motion.

This is a source-backed developer task. Implemented records source presence, not a final native, interactive or performance verdict.
