# Fortification path in the complete tree

Focus the Fortification path without leaving or filtering the shared graph.

Trap/wall/turret blueprints and ten rank nodes per type use the same prerequisites, milestone/payment preflight and selected-detail action as other personal upgrades. Existing blueprint/rank floors remain owned. This is no longer a separate fortification purchase screen; live plan authoring is documented under battle-build/saved-layouts.

Parent IDs express containment, not exclusive entry routes. Implemented records source presence, not native interaction or performance validation.
