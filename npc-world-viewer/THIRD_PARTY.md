# Third-party software

Original pixel-art graphics are authored in `src/art.ts`; no external game artwork is included.

- ExcaliburJS — BSD-2-Clause. https://github.com/excaliburjs/Excalibur
- Silkscreen by Jason Kottke — SIL Open Font License 1.1, distributed via
  `@fontsource/silkscreen` and self-hosted in the build. The package retains the complete license
  in `node_modules/@fontsource/silkscreen/LICENSE`.
- Zod — MIT. https://github.com/colinhacks/zod

Dependency packages retain their original copyright/license files. The npm lockfile pins the exact
distributed versions. Silkscreen's full font license is copied to `public/licenses/Silkscreen-OFL.txt`
and included in the built distribution.
