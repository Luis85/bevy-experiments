# Original Comet transport example

This is original Terra World content, licensed **MIT OR Apache-2.0** with the
project. The Python standard-library generator creates the mesh, materials,
named wheel rig and preview animation. No downloaded art, textures or fonts are
used. Regenerate only these new files with `python3 generate.py`; `--check`
compares all generated bytes without writing.

`comet.glb` is a compact hatchback with a detailed exterior, transparent glazing,
four empty cabin seats, a dashboard, separate rolling wheels and front steering
pivots. It follows the existing Comet dimensions of 1.9 × 1.65 × 4.2 metres.
The `parked` and `rolling` clips are meaningful standalone export previews.
The runtime's declared wheel policy replaces preview wheel rotation with signed
admitted movement, preserves wheel phase at rest and reverses in reverse gear.
The original procedural cockpit remains in first-person possession.

The optional `pack.json` binds only `vehicle_model: compact`. Pickups, taxis,
trucks, generic background vehicles, wildlife and character customization retain
their existing appearance. The composed `../transport-authoring.recipe.json`
builds a pack containing this Comet and all five unchanged original wildlife
models. The ready-to-load `../transport-demo.pack.json` references those same
six GLBs from their existing paths, without copying or modifying them. Use the
authoring workflow in `docs/ASSET_AUTHORING.md` from the project root. The
default wildlife pack is unchanged. Generated-pack paths and names give the
recipe-built pack a different identity from the direct demo manifest.

The sample has one fixed teal/ivory livery; it does not reinterpret the saved
paint selection. Garage explains this fixed livery and disables paid paint for
the selected Comet; queued clicks recheck the current model before charging.
Other procedural vehicles retain paid paint. This is not a production
material/LOD qualification. Empty seat meshes
do not imply passenger occupancy. Seated humans, boarding transitions, dynamic
paint/attachments, audio and target-hardware qualification remain separate work.
