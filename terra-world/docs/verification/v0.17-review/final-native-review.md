## Limits and remaining product work

These are expert-operated finite scenarios on Linux x86_64, Xvfb and software
Vulkan. The actual captured sizes are 1440 × 900 and 1100 × 700 with 150% text.
Software-rendered frame intervals and operator settling/input holds are not a
target-hardware performance result. The reference Windows PC, physical GPUs,
controllers/wheels, assistive technology, measured contrast and localization
remain unqualified.

The terminal storage-worker path and stale rental/assignment actions have source
and executed regression evidence. No native worker-loss injection, completed
rental return, accepted-job delivery or broad transaction balance is inferred
from this set of screenshots. Uncoached comprehension, longer careers, larger
populations, arbitrary dense traffic, long storage/WAN soaks and deployment
recovery objectives remain in the [current gap register](../../REVIEW_GAPS_v0.17.md).
