## Prioritized next increments

1. **Windows and physical-device proof:** run the shipped build path on the intended
   PC, capture actual local/remote creation, control, save/reopen and recovery,
   then record supported runtime/device conditions. This remains the most direct
   handoff gap for the user's machine.
2. **Observed full player journeys:** novice and returning players should complete
   Supply, Home/Community and Road/Company paths without developer coaching.
   Record specific confusion, dead ends, first useful action and recovery. Use
   those findings to guide progression and interface work.
3. **Measured runtime budgets:** physical GPU frame/loading/residency and storage
   transition/checkpoint tails on representative content; explicit acceptable
   targets before expanding world limits.
4. **Community and economic policy:** asset-owning succession/dissolution and
   sustainable long-career treasury/labor/capital flows with conserved-state
   fixtures. Avoid imposing an invented refund or takeover rule.
5. **Production and operational scope:** licensed regional content, complete art/
   audio, supported migration, signed upgrades, accounts/moderation and offsite
   recovery in a named deployment with responsible owners.

## Managed continuity boundaries

The launch witness means initialization was admitted; it does not mean a save
succeeded. A crashed first session without valid progress still fails closed.
The lease means a participating current process holds that managed world; its
file alone does not mean a live process exists. The session handle is retained
through final metadata writes and is released on closure or process death.

Published-but-unconfirmed output is retained for inspection/recovery. Do not
delete a witness or lock to force admission, overwrite an uncertain backup in
place, or interpret a retained inner recovery bundle as a completed native
wrapper. Follow the exact failure message and supported recovery guide. Keep
complete managed folders and external source dependencies for raw archival
copies; use verified recovery for path-bound relocation.
