5. **Production operations and content.** Select licensed data/art/audio,
   supported migration, trusted upgrades, public account/moderation and offsite
   recovery in a deployment with explicit responsibilities.

## Continuity and evidence boundaries

A launch witness records initialization admission, not successful saving. A
lease marker is coordination metadata, not evidence that its process is alive.
Maintenance may create the stable marker for a never-started world while leaving
its profile, witness and progress unchanged. Never delete a marker to force entry.

Native managed backup supports regional checkpoint worlds. Portable JSON worlds
retain their existing manual archival route. Backend online SQLite snapshots
remain distinct from native metadata-plus-progress backup. A completed inner
bundle is retained after a later wrapper failure but is not advertised as a
completed native backup.

Readiness is a current observation, not a reservation. A recipient replica's
missing destination does not establish complete-world absence. Actual commands
recheck authority and preserve goods/escrow on rejection.

Current work uses new v0.23 review, preflight, native, acceptance and delivery
directories. Earlier source/screenshots/receipts remain historical. Each final
claim names its actual platform, workload and identity; partial or failed runs
cannot authorize release packaging.
