- Added a persistent ecology layer with deer, boar, hare, fox and ibex; habitat capacity, foraging, resting, drinking, disturbance responses and bounded recovery use real living bodies and loaded terrain.
- Added finite and renewable resource patches for timber, stone, berries, fiber, fish, iron ore and fresh water; harvesting capability checks, fishing rods, iron processing and cooked fish share the existing inventory/crafting rules.
- Added named neighborhood, village and city charters, public material stocks and treasuries, infrastructure requirements, community experience, faction ownership and protected extraction/building rights.
- Added funded supply contracts driven by production shortages and retail demand, with escrow, physical fulfillment, private journals, bounded acceptance and world-time deadlines.
- Added stable scarcity price anchors and finite productive-resident pay. Improved logistics with source reservations, shortage-prioritized dispatch, bounded route retries, physical cargo return and adjacency/heap road search.
- Added Activities, Nature and Territory panels with next-step guidance, requirement/permission feedback, named delivery endpoints, visible waiting/retry counters, and the complete forage/fish/cook/eat/trade loop.
- Improved terrain materials, lighting, shadows, vegetation silhouettes, nearby grass/flowers, animated species meshes, resource depletion stages, terrain-draped territory markers and loaded courier visuals.
- Integrated all new systems with the host command path, bounded replicas and saves. Older reference catalogs are recognized exactly; customized catalogs remain unchanged. Loaded older living worlds receive additive initialization without resetting existing bodies or stock.
- Bumped the wire protocol to 2 so incompatible earlier clients fail at handshake instead of receiving unknown delivery phases or settlement commands. Saved-world migration remains separate from transport compatibility.
- Added independent domain, host/replica, whole-engine, renderer and native product verification. The release record separates measured behavior from production-MMORPG targets.

The immutable procedural source revision remains `terra-procedural-v2`; this release changes mutable gameplay and presentation. New state fields have defaults, while world/source identity checks still apply. Territory and ecology state are bounded in-memory reference systems, not a distributed planet-wide population or land database.

## 0.2.0 — Living world and native game pass

- Added an optional, reusable living-world plugin and persistent domain model for owned bodies, possession, RTS orders, needs, shops, money, production, NPC trade, traffic and courier cargo.
- Added first-person, third-person and RTS cameras/controls, crew selection, an owned rover and helicopter, contextual market/industry interfaces and visible interaction feedback.
- Increased the default native neighborhood to 49 chunks with 65×65 heightfields; added smooth indexed terrain, textured materials, richer map semantics, bounded feature detail tiers and render telemetry.
- Added georeferenced 8/16-bit PNG heightmap import and an explicitly synthetic demonstration dataset.
- Integrated new commands with authoritative multiplayer, existing inventories, building/farming/factions, source-world identity and durable saves.
- Hardened source-aware movement/placement, atomic admission, spawn residency, disconnect/resume, mixed-rate replica completeness and bounded payloads.
- Fixed traffic turn deadlocks, parked-vehicle queue stalls, distant source-road selection, road identity and snapshot truncation defects found by independent review and actual-map tests.
- Updated onboarding, integration, data, graphics, gameplay and multiplayer documentation; retained prior validation evidence separately.

The procedural base revision is now `terra-procedural-v2`. Local saves pin their base identity and reject incompatible old geometry. The living state is additive in domain serialization, but source/catalog changes still require deliberate host migration.
